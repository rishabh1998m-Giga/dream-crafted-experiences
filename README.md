# Dream Weaver Studio

Build a premium, immersive, highly interactive website for “Dream Corner”, a luxury event planning and experiential events company based in Bangalore.

I am attaching the official Dream Corner logo. Use the attached logo exactly as provided. Do not redraw, reinterpret, modify, recolor, stretch, distort, or create an alternative version of the logo. Extract the website’s visual language, color palette, contrast and overall mood from the logo.

CORE CREATIVE DIRECTION

Think like a top-tier Framer + Figma designer who creates award-winning websites for luxury hospitality, fashion, architecture, premium events and experiential brands.

The website should feel like a million-dollar event company, not a template, startup landing page, or AI-generated website.

The experience should communicate:

“Dream Corner doesn't just organise events. We create experiences people remember.”

The visitor should understand within the first 5–10 seconds:

 Who Dream Corner is

 What they do

 The scale/quality of their work

 Why their events are different

 That they create memorable, premium experiences

The website must be story-driven, not a collection of generic sections.

1. HERO — THE FIRST IMPACT

Create a cinematic full-screen hero.

Use a high-quality event video playing continuously in the background.

The video should feel like a luxury event film — celebrations, lighting, stage design, weddings, corporate experiences, people, atmosphere, details, movement.

Do NOT make the video feel like a generic stock-video website.

Layer the content elegantly over the video with strong contrast.

Hero messaging should be extremely clear and minimal.

Suggested direction:

DREAMS,
CRAFTED INTO
EXPERIENCES.

Then a short supporting statement:

Dream Corner creates unforgettable weddings, celebrations and experiences that turn moments into memories.

CTA:

Explore Our Work →

Secondary CTA:

Plan Your Event →

The typography should be large, editorial and luxurious, with excellent spacing.

Do NOT overcrowd the hero.

The hero should immediately feel like a premium creative studio / luxury event house.

2. VISUAL LANGUAGE

Build a sophisticated visual system around the attached Dream Corner logo.

Use its colors as the foundation, but do not simply apply the logo colors everywhere.

Create a refined palette with:

 Deep, rich primary tones derived from the logo

 Warm luxury neutrals

 Subtle metallic/highlight tones where appropriate

 Dark cinematic sections

 Occasional high-contrast light sections

The website should have texture and depth.

Absolutely avoid a completely flat white/black background.

Use subtle:

 Film grain

 Fine noise

 Paper/fabric-like texture

 Soft light falloff

 Extremely subtle gradients

 Atmospheric shadows

 Layered imagery

 Depth

 Elegant visual transitions

Keep textures extremely subtle and premium.

3. TYPOGRAPHY

Typography is extremely important.

Use a combination of:

Luxury editorial serif + modern sophisticated sans-serif.

Think:

 High-fashion magazine

 Luxury hotel

 Architectural studio

 Premium event house

Use oversized typography strategically.

Create dramatic typography moments such as:

WE DON'T
PLAN EVENTS.
WE CREATE
MEMORIES.

Typography should become part of the visual identity.

Avoid generic startup typography.

Avoid excessive bold rounded fonts.

Avoid typical AI-generated typography combinations.

4. NAVIGATION

Create a minimal floating navigation.

Logo on the left.

Navigation:

About
Experiences
Selected Work
Services
Contact

Keep navigation extremely clean.

On scroll, navigation should subtly transform rather than simply staying static.

Use smooth transitions and micro-interactions.

5. STORYTELLING SECTION

After the hero, introduce Dream Corner through storytelling rather than immediately showing a generic “About Us” block.

Create a section that communicates:

Creating infinite memories.

Explain that Dream Corner specialises in creating meaningful, beautifully executed experiences — from weddings and celebrations to corporate and large-scale events.

The visitor should understand the business naturally while scrolling.

Use a combination of:

 Large typography

 Cinematic imagery

 Subtle animations

 Layered composition

 Short copy

Avoid large walls of text.

6. SELECTED WORK — IMPORTANT

Create a premium SELECTED WORK section featuring exactly 6 projects.

This section MUST use a horizontal scrolling experience.

As the visitor scrolls vertically, the section should intelligently translate into horizontal movement.

Each project should feel like an individual visual story.

Each card/project should contain:

 Large cinematic image/video

 Project name

 Event category

 Location

 Short description

Example categories:

Luxury Wedding
Corporate Experience
Destination Wedding
Brand Experience
Social Celebration
Large-Scale Event

The horizontal scroll should feel extremely smooth and intentional.

Add subtle:

 Parallax

 Image movement

 Scale transitions

 Typography animations

 Progress indicator

Do NOT make it look like a standard horizontal card carousel.

Think award-winning Framer portfolio interaction.

7. SERVICES

Create a visually interesting services section.

Possible services:

Weddings
Corporate Events
Destination Events
Brand Experiences
Social Celebrations
Production & Event Design

Do not present them as six boring rectangular cards.

Instead, experiment with:

 Large typography

 Hover reveals

 Image transitions

 Interactive list

 Full-width sections

 Cursor interactions

When the visitor hovers over a service, an associated image/video should appear or transform.

Make this section feel alive.

8. “WHY DREAM CORNER”

Create a strong brand positioning section.

Do not use generic marketing claims like:

“Professional Team”
“Best Quality”
“Customer Satisfaction”

Instead communicate the philosophy behind Dream Corner.

For example:

Every celebration has a story.
We make sure yours is unforgettable.

Then explain the combination of:

Creative Direction
Planning
Production
Design
Execution
Experience

Keep it emotionally driven.

9. SOCIAL PROOF / SCALE

Dream Corner's Instagram indicates:

2500+ clients
Established 2020
Bangalore

Use these facts elegantly as part of the storytelling.

Do NOT make this look like a generic statistics section.

Create an editorial numerical moment:

2,500+
CLIENTS

SINCE
2020

etc.

Animate numbers subtly as they enter the viewport.

10. INSTAGRAM / SOCIAL MOMENT

Create an immersive visual section inspired by Dream Corner's social presence.

Use a sophisticated editorial grid rather than a generic Instagram feed.

The purpose is to make the visitor feel:

“I want to see more of their work.”

Include a CTA to Instagram.

11. CONTACT / CONVERSION

The final section should feel like the beginning of an experience rather than a boring contact form.

Large statement:

LET'S CREATE
SOMETHING
UNFORGETTABLE.

Then a minimal enquiry interaction.

Fields:

Name
Phone
Email
Event Type
Event Date
Tell us about your event

CTA:

START THE CONVERSATION →

Make the form visually beautiful and minimal.

12. CURSOR — IMPORTANT

Create a custom luxury cursor.

Do NOT use the default browser cursor.

The cursor should be subtle and sophisticated.

Possible behaviour:

 Small custom circular cursor

 Expands when hovering interactive elements

 Changes state over images

 Shows contextual text such as VIEW, EXPLORE, or OPEN

 Smooth magnetic interaction around buttons

 Slight trailing motion

Keep it elegant.

No gimmicky neon cursor.

It should feel like a premium interactive website.

13. MICRO-INTERACTIONS

The website should constantly feel alive.

Use tasteful:

 Scroll-triggered reveals

 Text masking animations

 Image reveals

 Parallax

 Scale transitions

 Hover interactions

 Magnetic buttons

 Smooth page transitions

 Section transitions

 Cursor interactions

 Subtle grain movement

Animations should feel cinematic and intentional, never excessive.

14. IMAGE & VIDEO TREATMENT

Photography is extremely important.

Images should feel:

 Cinematic

 Editorial

 Emotional

 High-end

 Atmospheric

 Human

Avoid generic corporate stock photography.

Use large imagery wherever possible.

Images should sometimes break outside conventional grids to create an art-directed composition.

15. DESIGN RULES — VERY IMPORTANT

DO NOT create:

 Generic SaaS layouts

 AI-looking gradients

 Purple/blue AI gradients

 Excessive glassmorphism

 Generic rounded cards

 Cookie-cutter hero sections

 Huge amounts of text

 Generic icon grids

 Stock-template layouts

 Excessive floating blobs

 Cheap-looking 3D elements

 Overly colourful UI

 Generic “modern startup” aesthetics

The website must NOT look AI-generated.

It should look like an experienced creative director and award-winning digital designer spent weeks designing it.

Think:

Luxury × Editorial × Cinematic × Experiential × Minimal

16. 3D / IMMERSIVE ELEMENTS

Use 3D and depth only where it genuinely improves the experience.

Do not add random 3D objects just to say the website is 3D.

Use depth through:

 Layered imagery

 Perspective

 Parallax

 Cinematic transitions

 Scroll-based movement

 Typography

 Image distortion where appropriate

 Atmospheric lighting

Performance must remain excellent.

17. MOBILE EXPERIENCE

The mobile version must NOT simply be a compressed desktop version.

Re-design the interactions specifically for mobile.

Maintain:

 Cinematic hero

 Strong typography

 Storytelling

 Smooth transitions

 Selected Work experience

 Premium visual hierarchy

For horizontal Selected Work on mobile, create a natural swipe/scroll interaction that feels intentional.

18. PERFORMANCE

Despite the rich visual experience:

 Optimise all images

 Lazy-load heavy media

 Optimise video

 Avoid unnecessary JavaScript

 Maintain smooth scrolling

 Avoid animation jank

 Ensure fast initial loading

 Respect reduced-motion preferences

The website should feel premium
